# Project 0: Foundations of Python for Security

## Project Overview
This initial project focused on establishing a professional coding environment using Jupyter Notebooks. As a security analyst, I practiced the essential skills of documenting code and displaying information—key components for reporting and automation.

## Tasks Completed
* **Markdown Documentation:** Practiced using Markdown to create headers and formatted text for clear security reporting.
* **Effective Commenting:** Implemented Python code comments (`#`) to document the purpose of scripts, ensuring future readability and collaboration.
* **Output Generation:** Utilized the `print()` function to display strings and verify program execution.

## Key Takeaways
"Print statements are vital to display the information from running a program back to you in a logical, easy fashion. Comments are very important to keep track of why the code is written and so others can know what the purpose is of the code." — *Lab Reflection*
