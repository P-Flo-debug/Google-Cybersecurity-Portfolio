# Project 4: Modular Security Tools with Functions

## Project Overview
In this project, I focused on making my security scripts more efficient and modular by defining custom Python functions. As a security analyst, reusing code through functions is vital for maintaining clean workflows, especially when performing repetitive tasks like log analysis or generating security alerts.

## 🔗 Project Link
* **[View Full Jupyter Notebook](./Activity_Define_and_call_a_function.ipynb)**

## Tasks Completed
* **Custom Security Alerts:** Defined and called an `alert()` function to display standardized messages for potential security issues, which can be reused across different scripts.
* **Iterative Alert Systems:** Modified functions to include `for` loops, allowing for multiple alert repetitions within a single function call.
* **Data Transformation:** Developed a `list_to_string()` function to convert a list of authorized usernames into a single string for better reporting and file compatibility.
* **String Concatenation:** Utilized the addition operator (`+`) to merge individual data pieces and added formatting (commas and spaces) to ensure output readability.


## Key Takeaways
> "Functions are crucial in coding. It simplifies processes when writing code to execute as you can call on a specific function thats already defined or one you create. More efficient workflows. Also, strings can be combined together using the + operator (string concatenation)."

## Technical Skills Used
* **Language:** Python 3
* **Concepts:** Function Definition (`def`), Function Calling, String Concatenation (`+`)
* **Iteration:** `for` loops within functions
* **Formatting:** Improving output readability with separators
