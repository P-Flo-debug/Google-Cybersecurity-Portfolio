# Project 01: Managing Security Data with Variables

## Project Overview
In this project, I applied Python programming fundamentals to manage security-related information. I practiced assigning and reassigning variables to track user data and utilized comparison operators to automate security checks.

## 🔗 Project Link
* **[View Full Jupyter Notebook](./Activity_Assign_Python_variables.ipynb)**

## Tasks Completed
* **Variable Management:** Assigned and updated variables for usernames, login attempts, and maximum permitted attempts.
* **Data Type Analysis:** Used the `type()` function to identify and categorize security data (Integers, Strings, Booleans, and Lists).
* **Automated Logic:** Employed the `<=` operator to compare current login attempts against security thresholds, generating boolean values for access control.
* **List Operations:** Created and updated lists of authorized users to simulate basic access control lists.



## Key Takeaways
> "My key takeaways include assigning and reassigning variables, and finding their data types using the type() function. I also used the <= operator to compare variables to get a boolean value (True/False) which is very helpful for mapping login attempts to maximum number of attempts allowed."

## Technical Skills Used
* **Language:** Python 3
* **Concepts:** Variable Assignment, Reassignment, Comparison Operators (`<=`)
* **Data Structures:** Lists (Array-style management)
* **Functions:** `print()`, `type()`
