# Project 02: Automated Access Control with Conditionals

## Project Overview
In this project, I developed a Python script that automates access control decisions. By implementing conditional logic, the script can determine whether a login attempt should be allowed based on multiple criteria, such as user authorization status and time-of-day restrictions.

## 🔗 Project Link
* **[View Full Jupyter Notebook](./LAB_Activity_CreateAConditionalStatement.ipynb)**

## Tasks Completed
* **Conditional Branching:** Used `if`, `elif`, and `else` statements to create distinct execution paths for authorized vs. unauthorized access.
* **Boolean Logic:** Applied comparison operators (`==`, `>`, `<`) to evaluate security criteria.
* **Complex Conditions:** Combined multiple security checks into single lines of code using logical operators (`and`, `or`) to increase efficiency.
* **Access Messaging:** Built a system that provides clear feedback based on why a login was accepted or rejected.



## Key Takeaways
> "Conditional statements give you the ability to determine whether specific criteria has been met. The if, elif, and else conditionals are great and make for concise code. Combining in logical operators such as 'and' and 'or' allows more than one condition to be checked which translates to less code that needs to be written."

## Technical Skills Used
* **Language:** Python 3
* **Control Flow:** Conditional Statements (`if`, `elif`, `else`)
* **Logic:** Logical Operators (`and`, `or`), Comparison Operators (`==`, `!=`, `<`, `>`)
