# Course 7: Automating Cybersecurity Tasks with Python 🐍

This section of my Cybersecurity Portfolio focuses on using Python to streamline security workflows, analyze logs, and manage access control through automation.

## 🛠️ Skills Acquired
* **Python Fundamentals:** Writing scripts, using variables, and managing data types.
* **Logic & Iteration:** Implementing conditional statements and `for`/`while` loops for log analysis.
* **File Handling:** Reading, parsing, and updating security-related text files.
* **Regular Expressions (Regex):** Extracting specific patterns like IP addresses and error codes.
* **Library Usage:** Leveraging the `os` and `re` modules for system automation.
