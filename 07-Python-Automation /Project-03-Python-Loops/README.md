# Project 3: Iterative Automation with Loops

## Project Overview
In this project, I practiced using Python's iterative statements to automate repetitive processes. Automation via loops is a critical skill for security analysts, allowing for the efficient investigation of multiple network events, such as login attempts or IP connection requests, without manual intervention for each item.

## 🔗 Project Link
* **[View Full Jupyter Notebook](./Activity_Create_loops.ipynb)**

## Tasks Completed
* **Fixed Iteration (For Loops):** Used `for` loops to iterate through lists of IP addresses and sequences of numbers using the `range()` function.
* **Conditional Iteration (While Loops):** Implemented `while` loops to repeat actions as long as specific security conditions remained true.
* **Automated ID Generation:** Created a loop to generate and display employee IDs, incorporating conditional logic to stop or alert at specific benchmarks (e.g., ID 5100).
* **System Monitoring Simulation:** Wrote a loop that simulated a connection retry mechanism, displaying "Connection could not be established" until a threshold was met.



## Key Takeaways
> "A for loop is used when you know how many times you want to repeat something, like going through a list. A while loop is used when you want to keep repeating something until a condition changes. This is vital for tasks like monitoring a system until a specific security event occurs."

## Technical Skills Used
* **Language:** Python 3
* **Iteration:** `for` loops, `while` loops
* **Functions:** `range()`, `print()`
* **Logic:** Loop control variables and incrementing
