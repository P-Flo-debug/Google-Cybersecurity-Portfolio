# Project 2: Risk Register & Threat Analysis 📊

## Project Overview
This project documents a comprehensive risk assessment for a fictional organization's financial assets. By identifying specific threats and vulnerabilities, this register provides a roadmap for prioritizing security controls.

## Risk Assessment Framework
Risks were evaluated using a quantitative scoring system:
* **Likelihood:** Probability of occurrence (1-3).
* **Severity:** Potential impact (1-3).
* **Priority Score:** Calculated as $Likelihood \times Severity$.

## Top Priority Risks
| Asset | Risk | Priority Score |
| :--- | :--- | :--- |
| Funds | Business Email Compromise (BEC) | 9 (Critical) |
| Funds | Compromised User Database | 9 (Critical) |
| Funds | Internal Theft | 6 (High) |

## Mitigation Objectives
* **Access Control:** Implement MFA to neutralize BEC threats.
* **Encryption:** Upgrade database standards for customer PII.
* **Network Security:** Secure public-facing backup servers.
