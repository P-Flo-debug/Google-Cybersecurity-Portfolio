# Project 3: Data Privacy & Least Privilege Analysis 🔐

## Project Overview
This project focuses on identifying gaps in data handling and privacy. I analyzed an incident where a failure to implement the **Principle of Least Privilege (PoLP)** led to a confidential business leak.

## Key Framework Applied
* **NIST SP 800-53: AC-6 (Least Privilege):** Evaluated current controls and proposed technical enhancements.



## Proposed Solutions
1. **Role-Based Access Control (RBAC):** To restrict marketing teams from analytics folders.
2. **Automated Access Revocation:** Implementing technical controls to expire shared links.
