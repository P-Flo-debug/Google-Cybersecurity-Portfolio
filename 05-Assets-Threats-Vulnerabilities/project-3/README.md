# Project 3: Data Privacy & Least Privilege Analysis 🔐

## Incident Analysis
Analyzed a real-world scenario involving a data leak at an EdTech company. A failure to revoke temporary folder permissions led to the unauthorized disclosure of confidential business plans on social media.

## Framework Application: NIST SP 800-53 (AC-6)
Applied the **Principle of Least Privilege (PoLP)** to propose a systemic shift in security posture:

1. **Role-Based Access Control (RBAC):** Restricting "Customer Success" roles from internal analytics folders.
2. **Automated Access Revocation:** Implementing technical controls to expire shared links automatically after project completion.

## Professional Justification
Moving from a "manual-only" permission model to an automated system reduces the risk of human error which is the leading cause of internal data breaches.
